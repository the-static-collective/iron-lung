# Iron Lung v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic TypeScript v0.1 that proves Iron Lung's own-birth specimen: every transfer remains a three-stranded braid, damaged braids remain circulable, admitted capabilities expose a bounded repair manifold, multi-route forks ascend a proposal-only Continuity Spine boundary, present authority selects, repair creates an immutable descendant, and assimilation remains distinct from transport and admission.

**Architecture:** Use small pure modules with no runtime network or cross-repository dependency. Literal braid/circulation/repair state is modeled independently from pneuma interpretation; capability admission and route selection are supplied explicitly from outside evaluators. The executable own-birth specimen is a local replay script over a pinned JSON fixture, not a workflow engine or autonomous router.

**Tech Stack:** TypeScript, Node.js 22, ESM, Node's built-in `node:test`, `tsx` for test/script execution, GitHub Actions. No runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-08-19-iron-lung-v0.1-design.md`

## Global Constraints

- Every braid contains exactly three named strands: `substance`, `lineage`, and `authority`.
- Strand conditions are exactly `intact | strained | unknown | refused | broken`.
- A domain truth of no asserted value is represented by an explicit `{ "kind": "none" }` claim; a strand is never omitted.
- No aggregate health/confidence score may erase disagreement between strands.
- Damaged or refused braids remain circulable after structural validation; circulation does not imply admission or assimilation.
- Capability registrations do not become routable merely by self-declaration; admitted capability IDs are supplied separately to circulation evaluation.
- Circulation discovers bounded capability matches; it never performs repairs.
- `no_route` is a valid result and must not cause a fabricated route.
- Multiple lawful routes return the complete bounded route set and never auto-select.
- Continuity Spine annotations/rankings remain `proposal`; they cannot select or authorize a route.
- Present route selection is a separate explicit input with authority and witness references.
- Repair produces a descendant braid with `parentId`; it never mutates an ancestor.
- Repair may change only a strand declared by the selected capability and only to a condition declared by `mayProduce`.
- Repair may not erase prior lineage references or silently widen authority.
- Descendants are re-evaluated from current state; route assumptions are not inherited.
- Assimilation is a structural eligibility result only; it does not constitute external ecosystem state.
- Literal evaluators never accept pneuma annotations as evidence, authority, witness, or route selection.
- Pneuma annotations are always `interpretive` and cannot rewrite literal state.
- Pure evaluators are deterministic, sort order-insensitive input sets, and do not mutate inputs.
- Expected domain refusals are returned as finding codes; no error path silently deletes the triggering braid.
- v0.1 has no thermodynamic simulation, physical energy/entropy accounting, theology-as-measurement, autonomous repair, autonomous route selection, network transport, generic service mesh, scheduler, AI planner, cross-repository mutation, or direct runtime dependency on TranchNode.
- The own-birth specimen is local evidence only; it does not promote Braided Transfer or Repair Manifold to a shared ecosystem Pattern.

Create `src/model.ts` with these public shapes:

```ts
export const STRAND_NAMES = ["substance", "lineage", "authority"] as const;
export type StrandName = (typeof STRAND_NAMES)[number];

export const STRAND_CONDITIONS = ["intact", "strained", "unknown", "refused", "broken"] as const;
export type StrandCondition = (typeof STRAND_CONDITIONS)[number];

export type StrandClaim =
  | { kind: "refs"; refs: string[] }
  | { kind: "none" };

export interface BraidStrand {
  condition: StrandCondition;
  claim: StrandClaim;
}

export interface BraidV01 {
  schema: "iron-lung/braid/v0.1";
  id: string;
  parentId?: string;
  strands: {
    substance: BraidStrand;
    lineage: BraidStrand;
    authority: BraidStrand;
  };
}

export type FindingCode =
  | "invalid_braid"
  | "missing_strand"
  | "invalid_strand_state"
  | "invalid_capability"
  | "unadmitted_capability"
  | "no_repair_route"
  | "multiple_routes_require_selection"
  | "proposal_only"
  | "invalid_spine_proposal"
  | "unknown_route_selection"
  | "repair_scope_violation"
  | "authority_escalation"
  | "lineage_erasure"
  | "ancestor_mutation"
  | "assimilation_blocked"
  | "missing_witness"
  | "invalid_pneuma_annotation";

export interface Finding {
  code: FindingCode;
  detail: string;
  refs: string[];
}

export type Result<T> =
  | { ok: true; value: T; findings: Finding[] }
  | { ok: false; findings: Finding[] };

export function sortUniqueStrings(values: readonly string[]): string[] {
  return [...new Set(values)].sort((a, b) => a.localeCompare(b));
}
```
