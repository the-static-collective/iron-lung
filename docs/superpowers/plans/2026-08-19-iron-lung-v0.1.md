# Iron Lung v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove Iron Lung's own-birth specimen with a deterministic local TypeScript model of three-strand braided circulation, capability-based repair routing, proposal-only Continuity Spine escalation, explicit present selection, immutable descendant repair, and structurally separate assimilation and pneuma layers.

**Architecture:** Small pure modules only. Literal state never depends on pneuma interpretation; capability admission and present route selection are explicit supplied inputs; a script-only first-breath replay composes the pure modules over one pinned fixture without becoming a reusable workflow engine.

**Tech Stack:** TypeScript, Node.js 22, ESM, `node:test`, `tsx`, GitHub Actions. No runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-08-19-iron-lung-v0.1-design.md`

## Global Constraints

- Every braid has exactly `substance`, `lineage`, and `authority` strands.
- Strand conditions are exactly `intact | strained | unknown | refused | broken`.
- No claimed value is represented explicitly as `{ "kind": "none" }`; omission is invalid.
- Damaged/refused braids may circulate after structural validation.
- Transport, admission, and assimilation remain distinct.
- Capability registrations are not routable unless their IDs are separately admitted.
- Circulation discovers routes; it never repairs or selects.
- No route is a valid result; multiple routes return the complete bounded set.
- Continuity Spine output is always proposal-only; it may rank but never select or authorize.
- Present selection is a separate input carrying authority and witness references.
- Repair changes only a capability-declared strand and produces an immutable descendant with `parentId`.
- Repair cannot erase known lineage or silently widen authority.
- Descendants are re-evaluated from current state.
- Assimilation is structural eligibility only, not constitution of ecosystem truth.
- Pneuma is always `interpretive` and is never accepted by literal evaluators as evidence, witness, route selection, or authority.
- Pure evaluators normalize unordered sets, are deterministic, and never mutate inputs.
- Expected refusals use explicit finding codes.
- No network transport, thermodynamic simulation, theology-as-measurement, autonomous repair, autonomous selection, generic service mesh, scheduler, AI planner, cross-repo mutation, or runtime TranchNode dependency.
- The own-birth result is local project evidence only; it does not graduate Braided Transfer or Repair Manifold to a shared Pattern.

export type StrandName = (typeof STRAND_NAMES)[number];

  | "multiple_routes_require_selection" | "proposal_only" | "invalid_spine_proposal"

export type Result<T> = { ok: true; value: T; findings: Finding[] } | { ok: false; findings: Finding[] };
