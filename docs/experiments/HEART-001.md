Status: **deterministic executable experiment**

An old Recursive T5 Combinatrix / Heart-Lung design asked for a smallest falsifiable specimen before any model intelligence was introduced.

This slice performs that experiment.

Or is the surviving distinction:

```text

```

with the durable crossing receipt belonging to a receipt/transition layer rather than to generation?

## What this supports

- bounded combinatrix can remain plural;
- rank does not select;
- refusal survives;
- unresolved state survives;
- present admission is separate from proposal generation;
- generation does not mint authority;
- consequence creates an immutable descendant rather than rewriting B0;

## What this does not support

- T5 as a required implementation;
- an autonomous model loop;
- a separate generative Heart object;
- generated authority;
- automatic selection;
- cross-project protocol status.

For this specimen, **Heart does not need to be a separate generative machine**.
